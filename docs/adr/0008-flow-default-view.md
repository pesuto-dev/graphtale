# Flow is the default view; Procedure is retired from the UI

The runtime graph tab is named **Flow**. It is the first tab and the view shown
when a skill opens. Catalog stays the file inventory (second tab). The parked
writer remains **flow editor** — Flow is read-only; the editor would write.

`Procedure` stays in parser/type names and in skill markdown headings the
detector still recognises. Product UI, listing sentence, and diagnosis copy use
Flow.
