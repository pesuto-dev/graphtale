# Procedure view prioritises honest inspiration

Procedure nodes stay generic (script / agent / reference / gate) with special shapes only when the skill text expresses them. The layout must stay visually compelling so authors are inspired to rethink how the skill runs — without inventing steps for spectacle. When beauty and honesty conflict, honesty wins (hybrid confidence: no fake DAG).

This slice: light visual refresh (typography, spacing, edge styling; keep recognizable shapes). Deeper visual redesign is allowed later, after Procedure is functionally solid — Inspiration stays a first-class goal, not a post-ship nice-to-have.
