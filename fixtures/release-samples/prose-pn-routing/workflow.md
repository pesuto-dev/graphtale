# Workflow

```text
P   Intake
N1  Split
N2a Research
N2b Verify
N3  Combine
N4  Explain
N5  Investigate
N6  Return
```

P then N1.
From N1, run N2a and N2b in parallel.
After N2a and N2b, continue with N3.
From N3, if the request is a question, continue with N4; otherwise, continue with N5.
N4 then N6.
N5 then N6.
