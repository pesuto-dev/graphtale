# Frontend Design

Do not use generic AI aesthetics. Think about the audience and pick a strong typographic direction.

## Guidelines

- Typography should be distinctive.
- Avoid Inter, Roboto, and other default stacks.
- Color should come from the product, not a purple gradient.

There is no runtime workflow here — only taste constraints.
