# Long linear demo

A skill whose runtime is a single chain long enough to wrap.

## First Steps

1. **Read the request** — open what the user asked
2. **List the files** — see what already exists
3. **Sketch the plan** — pick the next edits
4. **Open the editor** — jump to the first file
5. **Draft the change** — write the smallest patch
6. **Run the checks** — type-check and unit tests
7. **Fix the failures** — keep the patch green
8. **Update the notes** — say why the change exists
9. **Review the diff** — scan for leftovers
10. **Tag the commit** — one focused message
11. **Push the branch** — so a review can start
12. **Tell the user** — what landed and what did not
